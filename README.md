## 📌 About

**Mathics** is a YouTube channel dedicated to making advanced mathematics visually stunning and easy to understand. Complex topics like calculus, linear algebra, number theory, and more are broken down through smooth, elegant animations — inspired by channels like 3Blue1Brown.

This repository contains the **source code** behind the animations used in the videos.

---

## 🎥 What You'll Find Here

Each file in this repo corresponds to an animation or video produced for the Mathics YouTube channel.

## 🚀 Running the Animations

### Prerequisites

- Python 3.x → https://www.python.org/downloads/
- Manim *(if used)* → https://docs.manim.community/en/stable/installation.html

### Run a specific animation

```bash
python Video1.py
```

Or with Manim:
```bash
manim -pql Video1.py SceneName
```
